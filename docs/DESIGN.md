# Дизайн-система Vantara — «Forge»

## Откуда взялся язык

Логотип — дубовый щит с двумя стальными топорами и кремовой кромкой. Отсюда
и метафора интерфейса: **щит**. Не «тёмная тема с акцентом», а поверхность,
которая закрывает пользователя, и кромка, по которой видно, что защита держит.

Палитра выведена из самого логотипа, а не подобрана отдельно.

## Палитра

| Роль | Токен | Значение | Где применяется |
|---|---|---|---|
| Сталь — корпус | `--vn-steel-900` | `#16181D` | Фон окна |
| | `--vn-steel-850` | `#1C1F25` | Панели интерфейса |
| | `--vn-steel-800` | `#23272E` | Поля, поверхности |
| | `--vn-steel-700` | `#2D323A` | Активная вкладка, всплывающие панели |
| Дуб — акцент | `--vn-wood-600` | `#5A3A28` | Акцент светлой темы |
| | `--vn-wood-500` | `#6E4733` | Фокус, выделение, активные элементы |
| Кромка — текст | `--vn-ember-200` | `#F0DCC0` | Основной текст и иконки |
| | `--vn-ember-100` | `#FFF6E8` | Текст на акцентном фоне |
| Защита | `--vn-guard` | `#6FBF9B` | HTTPS, щит активен, заблокировано |
| Внимание | `--vn-warn` | `#E0A458` | Частичная защита |
| Угроза | `--vn-threat` | `#D9584A` | Нет шифрования, угроза |

**Правило цвета:** `--vn-threat` не используется нигде, кроме настоящей угрозы
безопасности. Если красным подсвечена кнопка закрытия и незащищённое соединение,
пользователь перестаёт замечать второе.

Ни один компонент не задаёт цвет напрямую — только через токены из
`ui/chrome/vantara/tokens.css`. Смена темы должна быть сменой значений в одном
файле, иначе светлая тема расползётся.

## Форма

Радиус растёт вместе с размером элемента: мелкие элементы управления `5px`,
вкладки и поля `8px`, всплывающие панели `12–16px`. Это создаёт иерархию —
крупная поверхность читается как «слой над», а не как плоскость.

Сетка — шаг 4px. Все отступы кратны ему.

## Движение

Анимации несут смысл, иначе их нет. Каждая отвечает на вопрос пользователя:
откуда взялся элемент, куда он делся, что только что произошло.

| Длительность | Токен | Применение |
|---|---|---|
| 70 мс | `--vn-dur-instant` | Реакция на наведение и нажатие |
| 130 мс | `--vn-dur-fast` | Смена состояния, меню |
| 200 мс | `--vn-dur-base` | Появление панелей |
| 320 мс | `--vn-dur-slow` | Открытие вкладки |
| 520 мс | `--vn-dur-slower` | Пульс щита |

Кривые: `--vn-ease-decel` для появления, `--vn-ease-accel` для исчезновения
(уходит быстро — не задерживает), `--vn-ease-spring` для элементов, которые
должны ощущаться физическими, — вкладки и щит.

**Технические правила:**

1. Анимируем только `transform`, `opacity`, `filter`. Эти свойства обрабатывает
   композитор, остальные вызывают пересчёт раскладки и роняют кадры.
2. Ничего зацикленного, кроме индикатора загрузки. Вечная анимация в интерфейсе
   утомляет через минуту.
3. `prefers-reduced-motion` отключает движение. Это не опция, а требование
   доступности: анимации вызывают тошноту у людей с вестибулярными нарушениями.

## Иконки

Свой набор, а не готовая библиотека. Готовые наборы (Lucide, Phosphor, Tabler)
сделаны хорошо, но они стоят в тысячах продуктов и не несут характера — с ними
интерфейс выглядит как любой другой современный интерфейс.

**Правила набора** — нарушение любого разваливает набор на «почти похожие» иконки:

- Сетка 24×24, рабочая область 20×20 — по 2px поля со всех сторон
- Обводка 1.6, без заливок. Заливка только у парных «активных» состояний
  (звезда, закладка), и тогда обводка убирается
- Геометрия рубленая: прямые, углы 45° и 90°, минимум кривых — отсылка
  к скандинавским формам логотипа
- Скругление на стыках: голая геометрия в мелком размере выглядит дёшево
- Оптическая компенсация: круглые и диагональные формы на 3–5% крупнее
  прямоугольных, иначе кажутся мельче соседей

**Щит с диагональным крестом** — главный фирменный знак интерфейса, прямая
отсылка к скрещённым топорам логотипа.

Источник правды — `tools/build_icons.py`. Иконки описаны в одном словаре и
генерируются оттуда: и отдельные файлы, и спрайт. Поэтому набор не может
разъехаться по стилю — обводка и сетка заданы в одном месте.

```bash
python tools/build_icons.py    # 25 иконок + sprite.svg
```

**Как применять цвет.** Иконки в интерфейсе подключаются CSS-маской, а не как
картинки: `mask-image` плюс `background-color` из токена. Тогда цвет иконки
полностью в руках CSS и меняется вместе с темой и состоянием. Вариант через
`context-fill` работает только внутри chrome Firefox и не даёт такой свободы.

## Компоненты

| Файл | Отвечает за |
|---|---|
| `tokens.css` | Все переменные: цвет, форма, размеры, ритм, время |
| `animations.css` | Ключевые кадры, утилитарные классы движения |
| `base.css` | Окно, панели, кнопки, фокус, прокрутка |
| `tabs.css` | Вкладки: форма, состояния, открытие и закрытие |
| `navbar.css` | Адресная строка, индикатор соединения, щит, подсказки |
| `menus.css` | Меню, всплывающие панели, поиск по странице |
| `icons/` | Набор иконок и спрайт (генерируются) |

Порядок импорта в `userChrome.css` значим: токены объявляют переменные, дальше
компоненты в порядке слоёв интерфейса.

## Превью

`docs/preview/index.html` — макет окна браузера, каталог иконок и палитра
с переключателем темы. Он подключает те же `tokens.css` и `animations.css`,
что и браузер, поэтому физически не может разойтись с продуктом.

```bash
python -m http.server 8777    # затем docs/preview/index.html
```

Открывать по `http://`, а не по `file://`: спрайт иконок подгружается запросом,
и на файловом протоколе он блокируется политикой источника.

## Типографика

Системный шрифт (`system-ui`) — он уже подгружен, отрисован субпиксельно и
выглядит родным. Свой шрифт в интерфейсе браузера — лишние килобайты и риск
несовпадения метрик.

Размеры: `11px` вспомогательный, `12px` вкладки, `13px` основной, `15px`
заголовки панелей.

Шрифт логотипа (скандинавский, с рублеными засечками) — только для брендинга:
экран приветствия, «О программе», сайт. В интерфейсе он нечитаем в мелком кегле.

## Светлая тема

Не инверсия, а отдельная палитра. Фон — тёплый пергамент (`#EFE9E0`), а не
белый: холодный белый рядом с дубовым акцентом выглядит грязным. Акцент
смещается на `--vn-wood-600`, тени становятся коричневыми, а не чёрными.

## Доступность

- Контраст текста к фону — не ниже 4.5:1 (проверять при смене токенов)
- Состояние не передаётся одним лишь цветом: у индикаторов есть иконка или
  подпись, иначе дальтоники не видят разницы между «защищено» и «нет»
- Видимый фокус на всех интерактивных элементах
- Уважение к `prefers-reduced-motion` и `prefers-contrast`
