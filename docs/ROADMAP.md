# Дорожная карта Vantara

Этапы идут по принципу «каждый заканчивается чем-то, что можно запустить и
показать». Внутри этапа задачи можно тасовать, порядок этапов — нет: каждый
следующий опирается на инфраструктуру предыдущего.

---

## Этап 0 — Каркас · *готово*

- [x] Структура репозитория, лицензия MPL 2.0
- [x] Брендинг: логотип нарезан, иконки 16–512 и `.ico` собраны
- [x] Дизайн-система: токены цвета, формы, размеров, ритма и времени
- [x] Свой набор иконок (25 штук) с генератором из одного описания
- [x] Базовый интерфейс: окно, вкладки, адресная строка, меню
- [x] Библиотека анимаций
- [x] Светлая и тёмная темы из одного набора токенов
- [x] Превью интерфейса с переключателем темы
- [x] Профиль приватности (~90 настроек)
- [x] Скрипт dev-окружения

## Этап 1 — Живой интерфейс

Цель: браузер визуально становится Vantara, а не перекрашенным Firefox.

- [ ] Установить Firefox Developer Edition, прогнать `dev-profile.ps1`,
      выловить расхождения CSS с реальной вёрсткой
- [ ] Заголовок окна: свои кнопки управления, перетаскивание, режим без рамки
- [ ] Боковая панель: вкладки, закладки, история в едином контейнере
- [ ] Стили страниц `about:` — они сейчас выбиваются из оформления
- [x] Своя страница новой вкладки вместо страницы Mozilla: поиск с выбором
      системы, закреплённые ссылки, сводка защиты. Ноль сетевых запросов
      до действия пользователя — проверено
- [ ] Светлая тема: проверить каждый компонент, не только токены
- [ ] Скриншоты интерфейса в `docs/screenshots/`

**Готово, когда:** скриншот браузера узнаётся как Vantara без подписи.

## Этап 2 — Chrome-скрипты: поведение

Цель: интерфейс начинает делать то, чего в Firefox нет. Здесь нужен загрузчик
скриптов (`fx-autoconfig` или свой) — CSS больше не хватает.

- [ ] Загрузчик chrome-скриптов, подключённый к профилю
- [ ] **Щит**: живой счётчик заблокированного у адресной строки, пульс при
      блокировке (CSS уже написан, нужен JS-источник события)
- [ ] **Журнал утечек**: панель, показывающая исходящие запросы страницы в
      реальном времени — куда пошло, что заблокировано, что прошло.
      Ничего подобного во встроенном виде нет ни у кого
- [ ] Вертикальные вкладки с группами
- [ ] Палитра команд по `Ctrl+Shift+P`: переход по вкладкам, действия, настройки
- [ ] Иконка в трее: быстрое открытие приватного окна, пауза сети, выход
- [ ] Горячая перезагрузка интерфейса в dev-режиме

**Готово, когда:** есть функции, ради которых Vantara ставят вместо Firefox.

## Этап 3 — Сборка форка

Цель: `vantara.exe` со своим именем, иконкой и установщиком.

- [x] MozillaBuild 4.2.1 установлен
- [x] `surfer` подключён, версия движка зафиксирована на Firefox 156
- [x] Исходники движка скачаны в `engine/`
- [x] Брендинг: иконки, имя, цвет — генерируются из логотипа
- [x] Чужие адреса из инструмента сборки вычищены (см. `tools/fix-branding.py`)
- [x] Телеметрия и отчёты о сбоях отключены на уровне компиляции
- [x] Первая сборка: vantara.exe запускается, xul.dll на месте
- [x] Интерфейс внутри сборки, а не в профиле (`tools/sync-ui.py`)
- [x] Приёмка сборки по фактам (`tools/verify-build.py`)

- [ ] Установщик со строками Vantara
- [ ] Перенести `ui/chrome/` в `src/browser/themes/vantara/`
- [ ] Перенести `user.js` в заводские дефолты `browser/app/profile/vantara.js`
- [ ] CI: сборка на GitHub Actions, артефакты на каждый тег

**Готово, когда:** установщик ставит браузер, который выглядит и зовётся Vantara.

## Этап 4 — Приватность как функция продукта

До этого этапа приватность была набором настроек. Здесь она становится тем,
что пользователь видит и чем управляет.

- [ ] **Уровни защиты** переключателем: Обычный / Строгий / Крепость.
      Каждый уровень — согласованный набор настроек с честным описанием,
      что именно сломается
- [ ] Встроенный блокировщик на списках EasyList/uBlock, без расширений
- [ ] Очистка URL от меток отслеживания (`utm_*`, `fbclid`, `gclid`)
- [ ] Блокировка CNAME-маскировки трекеров — обход, который проходит
      сквозь обычные блокировщики
- [ ] Контейнеры по умолчанию: каждый сайт в своей изоляции без настройки
- [ ] DNS-over-HTTPS с выбором резолвера в интерфейсе
- [ ] Автоочистка данных сайтов по таймеру
- [ ] Отчёт «что о вас известно» — сводка по накопленным данным профиля

**Готово, когда:** на тестах приватности (Cover Your Tracks, EFF) результат
лучше, чем у Firefox из коробки, и это видно на скриншоте.

## Что берём из других браузеров

Список задач этапа 2 и дальше. Не «скопировать», а понять, зачем это сделано,
и сделать точнее.

| Откуда | Что | Как улучшаем |
|---|---|---|
| Arc | Палитра команд, боковая панель | Без облака и обязательного аккаунта |
| Zen | Вертикальные вкладки, разделение экрана | То же, но с изоляцией: панель = контейнер |
| Brave | Встроенная блокировка, Shields | Журнал утечек показывает, что реально ушло |
| Edge | Группы вкладок, спящие вкладки | Спящая вкладка теряет и сетевое состояние |
| Firefox | Контейнеры, Total Cookie Protection | Контейнеры без настройки, по умолчанию |
| Vivaldi | Глубокая настройка интерфейса | Настройки без лишней сложности |
| Tor Browser | Унификация отпечатка | Уровень «Крепость» без сети Tor |

## Что осознанно **не** делаем

Решения, зафиксированные заранее, чтобы к ним не возвращаться:

- **Своя реклама, партнёрские ссылки, криптовалюта.** Браузер о защите данных
  не зарабатывает на данных.
- **Телеметрия «анонимная, для улучшения продукта».** Никакой.
- **Аккаунт для базовых функций.** Браузер работает полностью без сервера.
- **Свой движок.** Gecko — и так один из трёх оставшихся в мире.
